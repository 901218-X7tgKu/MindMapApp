========================================
  マインドマップアプリ - 使い方ガイド
  ファイル名: mindmap.html
========================================

【起動方法】
mindmap.html をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけで使えます。
インターネット接続は初回のアイコン読み込み時のみ必要です。
インストール不要・1ファイル完結です。


----------------------------------------
  ノードの基本操作
----------------------------------------

左クリック
  ノードを選択します。

ドラッグ（左クリック＆ドラッグ）
  ノードを自由に移動できます。

Ctrl + 左クリック（ノードがない場所）
  クリックした場所に新しいノードを追加し、
  すぐにテキスト編集状態になります。

右クリック
  テキストノード：その場でテキスト編集を開始します。
    - Enter キーで確定
    - Escape キーでキャンセル（元のテキストに戻る）
  画像ノード：編集モーダルを開きます（コメント・サイズ変更）。

Shift + 右クリック
  選択したノードを削除します。
  ※ ルートノード（中央の親ノード）は削除できません。

Ctrl + 右クリック × 2（2つのノードを順番に）
  2つのノードを接続します。
  すでに接続済みの場合は、接続を削除します。
  操作後に画面下部にトーストメッセージが表示されます。
  ※ 同じノードを2回選ぶとキャンセルされます。


----------------------------------------
  キャンバス操作
----------------------------------------

ホイールスクロール
  カーソル位置を中心にズームイン／アウトします。
  範囲：20% ～ 400%

左クリック＆ドラッグ（空白部分）
  キャンバスのビューをパン（視点移動）します。
  ノードの位置は変わりません。

Shift + 左クリック＆ドラッグ
  すべてのノードをまとめて移動します。
  マップ全体の位置を調整したいときに使います。


----------------------------------------
  画像ノード
----------------------------------------

キャンバスへのドラッグ＆ドロップ
  画像ファイル（PNG / JPG / GIF など）をキャンバスに
  ドロップすると、その位置に画像ノードが追加されます。
  複数枚同時にドロップ可能です。

ツールバー「画像追加」ボタン
  ファイル選択ダイアログから画像を選んで追加できます。

コメントの追加・編集
  画像ノードを右クリックするとモーダルが開き、
  コメントを自由に入力・編集できます。

表示サイズの変更
  画像ノードを右クリックして編集モーダルを開くと
  「表示サイズ」スライダーが表示されます。
  スライダーを動かすとリアルタイムでサイズが変わります。
  範囲：80px ～ 500px（10px 刻み）
  高さは幅に連動して自動調整されます（幅の 2/3）。
  「保存」を押すと確定され、保存データにも反映されます。

削除・接続
  画像ノードも他のノードと同様に操作できます。
  Shift+右クリックで削除、Ctrl+右クリック×2 で接続。


----------------------------------------
  ツールバー
----------------------------------------

Undo（Ctrl + Z）
  直前の操作を元に戻します。最大80ステップ記録されます。

Redo（Ctrl + Y または Ctrl + Shift + Z）
  元に戻した操作をやり直します。

ノード追加
  キャンバス中央付近にランダムな色でノードを追加します。

接続（ボタン）
  ボタンを押して接続モードにし、2つのノードを
  左クリックで繋げます（Ctrl+右クリックでも可能）。

画像追加
  ファイルダイアログから画像ノードを追加します。

カラードット（6色）
  選択中のテキストノードの色を変更します。
  ターコイズ／ブルー／アンバー／コーラル／パープル／グレー
  ※ 画像ノードには適用されません。

削除
  選択中のノードを削除します（ルートノードは除く）。

保存/読込
  マップデータをファイルまたはテキスト形式で保存・読み込みできます。


----------------------------------------
  保存・読み込み
----------------------------------------

【ファイル保存（推奨）】
  「保存/読込」ボタンを押してモーダルを開き、
  ファイル名を入力して「ダウンロード保存」を押します。
  .mindmap 形式のファイルとして端末に保存されます。

【ファイル読み込み】
  「保存/読込」モーダルの「ファイルを選択」から
  .mindmap ファイルを選ぶと読み込めます。

【テキストコピー保存】
  モーダル内のテキストエリアにデータが表示されるので、
  コピーしてメモ帳などに貼り付けて保存することもできます。
  画像データ（Base64形式）も含まれます。
  ※ 画像が多い場合はテキストが大きくなります。

【フォーマット】
  MINDMAP v2 形式（人間が読めるプレーンテキスト）
  例：
    MINDMAP v2
    NODE 0 0 1 340 250 マインドマップ
    NODE 1 1 0 180 130 アイデアA
    IMGNODE 5 240 400 200 コメントテキスト||data:image/png;base64,...
    EDGE 0 1
    META nodeId=6

  IMGNODE の列順：id / 幅(px) / x座標 / y座標 / コメント||画像データ


----------------------------------------
  キーボードショートカット一覧
----------------------------------------

  Ctrl + Z          Undo（元に戻す）
  Ctrl + Y          Redo（やり直す）
  Ctrl + Shift + Z  Redo（やり直す）
  Enter             テキスト編集を確定
  Escape            テキスト編集をキャンセル


----------------------------------------
  マウス操作まとめ
----------------------------------------

  左クリック                  ノード選択
  左クリック＆ドラッグ        ノード移動
  空白で左クリック＆ドラッグ  ビューをパン
  Ctrl + 左クリック（空白）   その場にノードを追加
  Shift + 左クリック＆ドラッグ 全ノードをまとめて移動
  右クリック                  編集（テキスト入力 or 画像モーダル）
  Shift + 右クリック          ノードを削除
  Ctrl + 右クリック × 2      ノードを接続 / 接続を解除
  ホイール                    ズームイン／アウト


----------------------------------------
  その他
----------------------------------------

ダークモード対応
  OSのダークモード設定に自動で追従します。

動作環境
  モダンブラウザ（Chrome 90以降推奨）
  ※ Internet Explorer は非対応です。

インターネット接続
  初回読み込み時にアイコンフォント（Tabler Icons）を
  CDNから取得します。オフライン環境ではアイコンが
  表示されませんが、機能は正常に動作します。
