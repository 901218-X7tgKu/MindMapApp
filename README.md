# 🗺 マインドマップアプリ 使い方ガイド

**ファイル名:** `mindmap.html`

## 起動方法

`mindmap.html` をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけで使えます。インストール不要・1ファイル完結です。初回のみアイコンフォントの読み込みにインターネット接続が必要です。

---

## ノードの基本操作

| 操作 | 動作 |
|------|------|
| 左クリック | ノードを選択 |
| 左クリック＆ドラッグ | ノードを移動（単体） |
| Ctrl + 左クリック（空白） | その場に新しいノードを追加し、すぐ編集開始 |
| Ctrl + 左クリック（ノード上） | 子ノードの展開／折り畳みをトグル |
| Ctrl + 左クリック＆ドラッグ | ノードと全子孫をまとめて移動 |
| Shift + 左クリック（テキストノード） | ノードの色を順番に切り替え（6色ループ） |
| 右クリック | テキスト編集 / 画像モーダルを開く |
| Shift + 右クリック | ノードを削除（ルートノードは除く） |
| Ctrl + 右クリック × 2 | 2ノードを接続 / すでに接続済みなら解除 |

### テキスト編集（右クリックで開始）

- **Enter** で改行を挿入
- **連続2回 Enter**（600ms以内）で編集確定
- **ノードの外をクリック**しても確定
- **Escape** でキャンセル（元のテキストに戻る）
- 編集中はテキスト全体が見える状態でサイズが自動調整されます
- 1行のとき：中央配置・横幅が内容に合わせて伸びる
- 2行以上のとき：左寄せ配置・最長行の幅に合わせて広がる

## キャンバス操作

| 操作 | 動作 |
|------|------|
| ホイールスクロール | カーソル位置を中心にズームイン／アウト（20%〜400%） |
| 左クリック＆ドラッグ（空白） | ビューをパン（ノード位置は変わらない） |
| Shift + 左クリック＆ドラッグ | 全ノードをまとめて移動 |

## 親子ノード機能

### 親子関係の定義

接続した順番で **先に選んだノードが親・後が子** になります。子を持つ親ノードには `▶` マーク、折り畳み中は `▶▶` マークが表示されます。

### 展開・折り畳み

| 操作 | 動作 |
|------|------|
| Ctrl + 左クリック（親ノード） | 直接の子ノードのみ展開／折り畳み |
| Shift + Q | 全ノードを展開 |
| Shift + W | 全ノードを折り畳み |

> 孫ノードは子ノードを別途 Ctrl+クリックで操作します。

### 連動移動

- **Ctrl + ドラッグ**：親ノードと全子孫ノードをまとめて移動
- **通常ドラッグ**：そのノードのみ移動

折り畳み状態は保存データに含まれ、読み込み後も復元されます。

---

## 画像ノード

### 追加方法

- **キャンバスへドラッグ＆ドロップ**（PNG / JPG / GIF など、複数枚同時可）
- **ツールバー「画像追加」ボタン**からファイルを選択

### 編集（右クリックでモーダルを開く）

- **コメント**：自由にテキストを入力・編集
- **表示サイズ**：スライダーで 80px〜500px（10px刻み）を変更、リアルタイムプレビューあり。高さは幅の 2/3 に連動

### その他

- Shift+右クリックで削除、Ctrl+右クリック×2 で他ノードと接続
- サイズ・コメントは保存データに含まれ、読み込み後も復元

---

## タイトルの変更

ヘッダーの「🗺 マインドマップ」部分をクリックするとその場で編集できます。

- **Enter** または外をクリックで確定
- ブラウザのタブタイトルも連動して変わります
- 保存データに含まれ、読み込み後も復元されます

## ツールバー

| ボタン | 動作 |
|--------|------|
| Undo | 直前の操作を元に戻す（最大80ステップ） |
| Redo | やり直す |
| ノード追加 | 中央付近にランダム色でノードを追加 |
| 接続 | 接続モードで2ノードを左クリックして繋げる |
| 画像追加 | ファイルダイアログから画像ノードを追加 |
| カラードット（6色） | 選択中のテキストノードの色を変更 |
| 削除 | 選択中のノードを削除 |
| ファイル | 保存・読み込みモーダルを開く |

## 保存・読み込み

### ファイル保存（推奨）

「ファイル」ボタン → ファイル名を入力 → 「ダウンロード保存」で `.mindmap` ファイルを保存します。

### ファイル読み込み

「ファイル」モーダルの「ファイルを選択」から `.mindmap` ファイルを選び、「このファイルを読み込む」を押します。

### データ形式

`MINDMAP v2` 形式のプレーンテキストです。

```
MINDMAP v2
TITLE プロジェクト計画
NODE 0 0 1 340 250 マインドマップ
NODE 1 1 0 180 130 アイデアA\n2行目テキスト
IMGNODE 5 240 400 200 コメント||data:image/png;base64,...
EDGE 0 1
COLLAPSED 3,5
META nodeId=6
```

| フィールド | 説明 |
|-----------|------|
| `NODE` | `id / colorIdx / isRoot / x / y / テキスト`（改行は `\n` でエスケープ） |
| `IMGNODE` | `id / 幅(px) / x / y / コメント\|\|画像データ(Base64)` |
| `COLLAPSED` | 折り畳み中の親ノードIDのカンマ区切り |

## 動作環境

- **推奨ブラウザ**：Chrome 90以降
- Internet Explorer は非対応
- オフライン環境ではアイコンが表示されませんが、機能は正常に動作します
