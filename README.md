# 🗺 マインドマップアプリ 使い方ガイド

**ファイル名:** `mindmap.html` | **バージョン:** v2.18

## 起動方法

`mindmap.html` をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけで使えます。インストール不要・1ファイル完結です。初回のみアイコンフォントの読み込みにインターネット接続が必要です。

起動時は自動的にID最小のノード（通常はルートノード）が画面中央に表示されます。公開用HTMLでも同様です。

---

## 表示テーマ

ヘッダー右端の 🌙 **ダーク** / ☀️ **ライト** ボタンでテーマを切り替えられます。

- ボタンを押すたびにダーク・ライトが切り替わり、ノードの色も即時反映されます
- 選択状態は localStorage に保存され、次回起動時も維持されます
- 初回起動時のみ、保存がなければ OS の設定を初期値として引き継ぎます

## ノードの基本操作

| 操作 | 動作 |
|------|------|
| 左クリック | ノードを選択 |
| 左ダブルクリック | 子ノードがあれば展開／折り畳みをトグル（+ノード選択） |
| 左クリック＆ドラッグ | ノードを移動（単体） |
| Ctrl + 左クリック（空白） | その場に新しいノードを追加し、すぐインライン編集開始 |
| Ctrl + 左クリック × 2（ノード） | 2ノードを接続 / すでに接続済みなら解除 |
| Ctrl + 左クリック＆ドラッグ | ノードと全子孫をまとめて移動 |
| Shift + 左クリック（テキストノード） | ノードの色を順番に切り替え（8色ループ） |
| 右クリック | テキストノード：インライン編集 / 画像ノード：編集モーダルを開く |
| Ctrl + 右クリック | 属性編集モーダルを開く（URL・タグ・ステータス。画像ノードは画像・サイズ・コメントも同じモーダルで編集） |
| Shift + 右クリック | ノードを削除 |
| Ctrl + Shift + 右クリック | ノードのURL属性を別タブで開く（URL未設定のノードは反応しません） |

### テキスト編集（右クリックで開始）

- **Enter** で改行を挿入
- **Shift + Enter** で編集確定
- **ノードの外をクリック**しても確定
- **Escape** でキャンセル（元のテキストに戻る）
- 編集中はズームレベルに関係なく常に一定サイズで全文字が表示されます
- 1行のとき：中央配置・横幅が内容に合わせて伸びる
- 2行以上のとき：左寄せ配置・最長行の幅に合わせて広がる

### インライン書式（文字の色・サイズ変更、組み合わせ可）

ノードのテキストおよび画像ノードのコメントは、編集中に以下の記法を使うことで、部分的に色・フォントサイズを変更できます。

| 記法 | 効果 | 例 → 結果 |
|------|------|-----------|
| `\c[色名]文字\` | 「文字」部分の色を変更 | `\c[red]注意\` → 「注意」が赤文字に |
| `\f[サイズ]文字\` | 「文字」部分のフォントサイズを変更 | `\f[20]見出し\` → 「見出し」が20pxに |
| `\\c[色名]文字\\` のように何も装飾を開いていない場所で `\` を2つ重ねる | 直前の記法をエスケープし、そのまま文字として表示 | `\\c[red]文字\\` → `\c[red]文字\` とそのまま表示 |

- 色は `red` や `#ff0000`、`rgb(255,0,0)` など、CSSで使える色指定が利用できます
- サイズは `20` のように数値だけを書くと自動的に `px` 扱いになります（`1.4em` のような単位付き指定も可）
- 開始記法（`\c[...]`・`\f[...]`）に対応する終端の `\` が見つからない場合は、そこから行末（テキスト末尾）まで書式が適用されます

**色とサイズの組み合わせ（ネスト）**

`\c[...]` と `\f[...]` は入れ子にして組み合わせることができます。内側から順に `\` を重ねて閉じます。

- `\f[15]\c[red]テスト\\` → 「テスト」が15px・赤文字の両方になります（`\` を2つ重ねて、内側の色→外側のサイズの順に閉じる）
- 同時に指定できるのは色1種類・サイズ1種類までです。同じ種類のタグを二重に開いた場合は、内側（より深い）の指定が優先されます
- エスケープ（`\\` による記法の無効化）は、装飾を何も開いていない場所でのみ働きます。装飾を開いている最中（`\c[...]` や `\f[...]` の内側）に現れる `\` は常にその装飾を1つ閉じる記号として扱われます

- 編集中のテキスト入力欄には記法がそのまま表示されます。ノード確定後、通常表示（右クリック編集を終えた状態）で書式が反映されます
- 編集用HTML・公開用HTMLの両方で表示に反映されます

### URLを開く機能

ノードの **URL属性**（後述の「ノード属性」参照）に設定した値を、別タブで開きます。

- 編集用HTML・公開用HTML共通：**Ctrl + Shift + 右クリック**（編集用HTMLでは選択中ノードに対する **Ctrl + Shift + Enter** も同様）
- URL属性が未設定のノードは、Ctrl+Shift+右クリックしても何も起こりません
- `https://example.com` などのWebURLや `./pages/detail.html` などのローカルHTMLパスに使用できます
- 相対パスの場合は現在のHTMLを基点に解決して開き、見つからない場合は絶対パスとしてフォールバックします
- v1.x系にあった「ノード本文（テキスト／コメント）をそのままリンク先として開く」機能は **v2.00で廃止** されました。リンクを使う場合は必ずURL属性を設定してください

### ノード属性（URL・タグ・ステータス）

テキストノード・画像ノードのいずれにも、以下の3つの属性を設定できます。

| 属性 | 説明 |
|------|------|
| URL | リンク先。Ctrl+Shift+右クリック（またはCtrl+Shift+Enter）で開く |
| タグ | 複数設定可能。`#タグA#タグB#タグC` のように `#` 区切りで入力 |
| ステータス | 1つのみ設定可能な単一の値（自由入力） |

**編集方法（編集用HTMLのみ）**

- ノードを **Ctrl + 右クリック** すると「属性編集」モーダルが開きます
- テキストノードの本文はこのモーダルでは編集しません（本文編集は通常の右クリックによるインライン編集で行います）。モーダルにはURL・タグ・ステータスの3項目のみが表示されます
- 画像ノードは元々コメント編集がモーダル方式のため、通常の右クリック・Ctrl+右クリックのどちらでも同じモーダルが開きます。画像・表示サイズ・コメントを左側、URL・タグ・ステータスを右側にまとめた2カラム表示です
- 画像ノードのコメント欄には「コメントを表示」トグルがあり、OFFにするとその画像ノードはコメント欄が非表示になり画像のみの表示になります（コメントの文字自体は保持されるため、再度ONにすれば内容が復活します）。既定値はON。この設定は編集用HTMLのモーダルでのみ変更可能で、公開用HTMLでは変更できません（保存時点の表示状態がそのまま反映されます）
- ノード編集モーダルの属性欄（URL・タグ・ステータスと同じ場所）には「非公開にする（子孫ノードも含む）」トグルがあります。ONにすると、そのノードと配下の子孫ノードすべてが公開用HTML書き出しの対象から完全に除外されます。単なる非表示ではなく、公開用HTML生成時にノード・エッジ情報自体をデータから取り除く方式のため、書き出し後のファイルをテキストエディタで開いても非公開にした内容は含まれません。編集用HTML上では非公開ノードの右上に🔒バッジが表示され、見落としを防げます（テキストノード・画像ノード共通）
- 保存は「保存」ボタンまたは Shift+Enter、キャンセルは「キャンセル」ボタンまたは Escape

**閲覧方法（公開用HTMLのみ）**

- ノードを **右クリック** すると、タグ・ステータスを確認できる専用モーダルが開きます（閲覧専用・編集不可）
- URLを開きたい場合は別途 **Ctrl + Shift + 右クリック** を使用します

**検索との連携**

検索機能（Ctrl+F）は、ノード本文（テキスト／コメント）に加えて、タグ・ステータスの値も検索対象になります。編集用HTML・公開用HTMLの両方で対応しています。

### ホバーハイライト

ノードにマウスカーソルを乗せると、接続されているノードが色分けでハイライトされます。

| 色 | 対象 |
|----|------|
| 🟠 オレンジ枠 | ホバー中のノード自身 |
| 🔵 ブルー枠 | 親ノード（上位ノード） |
| 🟢 グリーン枠 | 子ノード（下位ノード） |

接続されているエッジもオレンジ色でハイライトされます。カーソルが外れると即座に解除されます。

## キャンバス操作

| 操作 | 動作 |
|------|------|
| ホイールスクロール | カーソル位置を中心にズームイン／アウト（1%〜400%） |
| 左クリック＆ドラッグ（空白） | ビューをパン（ノード位置は変わらない） |
| Ctrl/Cmd + ↑ / ↓ | 画面中央を基準にズームイン／アウト |
| C | 画面中央を基準に拡大率を100%にリセット |

- ツールバー内に現在の拡大率を表示する入力欄（例：「100%」）があり、ズーム操作のたびにリアルタイムで更新されます
- この入力欄はクリックすると値が全選択された状態で編集でき、任意の拡大率（1%〜400%）を直接入力できます。**Enter**で確定、**Escape**でキャンセル（元の値に戻る）、フォーカスを外すだけでも確定します。画面中央を基準にズームします。数値として認識できない入力の場合は確定されず、現在の拡大率表示に戻ります
- 1%まで縮小できるため、大規模なマインドマップでもノード数百個規模の全体構造を俯瞰する用途に使えます（ノード内容は視覚的に判読できなくなります）
- 編集用HTML・公開用HTMLの両方で利用できます

## 親子ノード機能

### 親子関係の定義

接続した順番で **先に選んだノードが親・後が子** になります。子を持つ親ノードには `▶` マーク、折り畳み中は `▶▶` マークが表示されます。

### 展開・折り畳み

| 操作 | 動作 |
|------|------|
| 左ダブルクリック（親ノード） | 直接の子ノードのみ展開／折り畳み |
| Shift + Q | 全ノードを展開 |
| Shift + W | 全ノードを折り畳み |

> 孫ノードは子ノードを別途左ダブルクリックで操作します。
> ※単純な左クリック（1回）ではノードの選択のみを行い、展開／折り畳みは反応しません（誤操作防止のため）。

### 連動移動

- **Ctrl + ドラッグ**：親ノードと全子孫ノードをまとめて移動
- **通常ドラッグ**：そのノードのみ移動
- **折り畳まれているノードをドラッグした場合**：Ctrlを押していなくても、子孫ノードが自動的に連動して移動します。子孫が画面上に見えていない状態で気づかずに大きく動かしてしまい、展開したときにノード配置が大きく崩れてしまうのを防ぐためです

折り畳み状態は保存データに含まれ、読み込み後も復元されます。

### ループ接続の禁止

接続操作の際、親子関係がループになる接続（例：A→B→C→D→A）は自動検出され、トーストメッセージで警告のうえ拒否されます。既存チェーンへの追加接続（例：A→B→C→D の状態で A→D）は通常通り接続できます。

### 子孫を含めた一括削除

ノードを左クリックで選択した状態で **Ctrl + Shift + L** を押すと、そのノードと配下の全子孫ノードをまとめて削除できます。

- 実行前に確認ダイアログが表示されます
  - 子孫がいる場合：「このノードと子ノード ◯個（計◯個）を削除します。よろしいですか？」
  - 子孫がいない場合：「このノードを削除します。よろしいですか？」
- 「OK」で削除を実行、「キャンセル」で何も起きません
- 削除後も **Ctrl + Z**（Undo）で元に戻せます
- 通常の **Shift + 右クリック** による削除は対象ノード単体のみが消えますが、本機能は子孫もまとめて削除します

## 検索機能

| 操作 | 動作 |
|------|------|
| Ctrl + F | 検索欄にフォーカス |
| テキスト入力 | リアルタイムで該当ノードをハイライト、最初のノードを画面中央に表示 |
| Enter または ▼ボタン または X | 次の結果へ移動（画面中央に表示） |
| ▲ボタン または Shift + X | 前の結果へ移動 |
| Escape | 検索クリア（検索フィルターも初期状態＝全てONに戻ります） |

- 🟠 オレンジ枠：検索に一致するノード
- 🔴 赤枠：現在フォーカスしているノード
- 検索対象は、テキストノードの本文・画像ノードのコメントに加えて、**タグ・ステータス**（ノード属性）も含まれます
- **X** / **Shift + X** は検索欄にフォーカスしていない状態（キャンバス操作中など）でも使え、検索結果が1件以上ある場合に反応します。検索欄にフォーカスしている間は通常の文字入力として扱われます
- 編集用HTML・公開用HTMLの両方で利用できます

### 検索フィルター

検索欄の右側にある漏斗（フィルター）アイコンをクリックすると、検索対象を絞り込むパネルが開きます。

- ☑ 通常ノード（本文）／☑ 画像ノード（コメント）／☑ タグ／☑ ステータス の4項目を個別にON/OFFできます（初期状態は全てON＝従来通りの全文検索）
- チェックを外した項目は検索対象から除外され、検索欄に文字が入力済みであれば即座に結果が再計算されます
- 例：「画像ノード」だけOFFにすれば、テキストノードのみを対象に本文・タグ・ステータスで検索できます。「タグ」だけONにすればタグの値のみを対象に検索できます
- 初期状態（全てON）から変更されている間は、フィルターボタンがハイライト表示されます
- パネルの外側をクリックすると自動的に閉じます
- 検索欄で **Escape** キーを押すと、検索クリアと同時にフィルターも初期状態（全てON）にリセットされます。初期状態から変更があった場合のみ、トースト通知「🔄 検索フィルターをデフォルトに戻しました」が表示されます
- 編集用HTML・公開用HTMLの両方で利用できます

## タグ・ステータス一覧（何もない場所での右クリック）

ノードや画像ノードがない、キャンバスの空白部分を右クリックすると、マップ全体で使われている**タグ・ステータスの一覧と件数**を表示するモーダルが開きます（タグ→ステータスの順で表示）。

- タグ・ステータスはそれぞれ件数の多い順（同数の場合は五十音順）に並びます
- 一覧の項目（例：「重要 (3)」）をクリックすると、その文字列がそのまま検索欄に入力され、検索機能と同じ挙動で該当ノードがハイライト・中央表示されます。クリックすると同時にこのモーダルは閉じます
- 項目クリック時、**検索フィルターもクリックした種別に合わせて自動的に絞り込まれます**。例えばタグをクリックした場合はフィルターの「タグ」のみON、それ以外（通常ノード・画像ノード・ステータス）はOFFになり、無関係な一致を避けてタグの値だけで検索できます。ステータスをクリックした場合も同様に「ステータス」のみONになります
- タグ・ステータスのどちらも1件も設定されていない場合は、それぞれ「〜が設定されたノードはありません」と表示されます
- ノード上やエッジ（線）上での右クリックは従来通りそれぞれの編集モーダルが開くため、干渉しません
- 編集用HTML・公開用HTMLの両方で利用できます

## 選択ノードの中央表示

ノードを左クリックで選択した状態で **F** キーを押すと、そのノードを画面の中央に表示します。

- 画面の端に追いやられたノードをすばやく見つけ直したいときに便利です
- 実行時にトースト通知「📍 ノードを中央に表示しました」が表示されます
- テキスト入力欄やタイトル編集中は無効です

## 次/前の接続グループへジャンプ（最若IDノードへ）

ノードを左クリックで選択した状態で **N** キーを押すと、そのノードが属する「つながり（接続されたノード群）」の**次のグループ**に移動し、そのグループの中で**最もIDが若いノード**を画面中央に表示します。**B** キーを押すと逆方向（前のグループ）に移動します。

- ここでいう「つながり」とは、親子関係や Ctrl+左クリック×2 による接続など、エッジで直接・間接につながっている一連のノード群のことです（マインドマップ上の1つの木・枝や、接続でつながったノード群がそれぞれ1グループになります）
- グループの分類・並び順は各グループの中で最もIDが若いノードを基準に決まります。選択中のノードがグループ内のどのノードであっても（末端のノードを選んでいても）、移動先は次/前のグループの最若IDノードになります
- 例えば `A→B→C→D`、`E→F→G→H`、`I→J→K→L`、`M→N→O→P` という4つの独立したつながりがある場合、A（1グループ目の最若ID）を選択して **N** を押すごとに `E → I → M → A → E …` の順に循環します。**B** を押すと逆方向 `A → M → I → E → A …` に循環します
- つながりが1グループしかない場合（すべてのノードが1つに接続されている、またはノードが1つしかない場合）はトースト「⚠ 他の接続グループがありません」が表示されます
- ノードを選択していない場合は無効です
- 実行時にトースト通知（「📍 次のグループのノードを中央に表示しました」/「📍 前のグループのノードを中央に表示しました」）が表示されます
- テキスト入力欄やタイトル編集中は無効です
- 編集用HTMLのみの機能です（公開用HTMLにはノード選択の概念がないため非対応）

## 最上位ノード／子孫内の最深ノードへジャンプ

ノードを左クリックで選択した状態で **T** キーを押すと、そのノードが属する接続グループ（N/Bと同じ「つながり」の単位）全体の中で**最も階層が高い（ルートに近い）ノード群**のうち、**最もIDが小さいノード**を画面中央に表示します。

**E** キーを押すと、選択中のノード**自身とその子孫ノードのみ**（グループ全体ではなく、選択ノードを起点にエッジを辿って到達できる範囲）を対象に、その中で**最も階層が深い（末端に近い）ノード群**のうち、**最もIDが大きいノード**を画面中央に表示します。選択ノードに子孫がない場合は選択ノード自身が対象になります。

- 「階層」は、そのグループ内で親を持たないノード（ルート）を階層0とし、エッジを1本たどるごとに1ずつ深くなるものとして算出しています。1つのノードに複数の親がある場合は、最も浅い経路の階層が採用されます（T・Eとも同じ算出方法を使用します）
- Tキーは対象範囲がグループ全体、Eキーは対象範囲が選択ノード以下の子孫のみという違いがあります。Tキーはグループの根本（大元の親）へ素早く戻りたいときに、Eキーは今選んでいる枝の一番深い子孫へ素早く辿り着きたいときに使えます
- ノードを選択していない場合は無効です
- 実行時にトースト通知（「📍 グループ内で最も階層の高い親ノードを中央に表示しました」/「📍 選択ノード以下で最も階層の深い子ノードを中央に表示しました」）が表示されます
- テキスト入力欄やタイトル編集中は無効です
- 編集用HTMLのみの機能です（公開用HTMLにはノード選択の概念がないため非対応）

## 最も若いIDのノードを中央表示

ノード編集中でない状態で **Z** キーを押すと、ID が最も若い（＝通常は最初に作成された）ノードを画面の中央に表示します。

- ノードを選択していなくても使えます
- 迷子になったときにマップの起点（ルート付近）へすばやく戻りたい場合に便利です
- 実行時にトースト通知「📍 最も若いIDのノードを中央に表示しました」が表示されます
- テキスト入力欄やタイトル編集中は無効です
- 公開用HTML（閲覧専用版）でも同じ操作で利用できます

## 同じ内容のノードへジャンプ

ノードを **Ctrl + Shift + 左クリック** すると、同じ内容（テキストノードは本文、画像ノードはコメント）を持つ他のノードを探し、見つかった場合はそのノードを画面中央に表示します。

- 用語集や参照関係など、同じキーワードを複数箇所に配置しているマップで、対応するノード同士をすばやく行き来したいときに便利です
- 一致するノードが複数ある場合は、同じノードに対して連続でCtrl+Shift+クリックすることで順番に巡回します（トーストに「(1/2)」のように現在の位置が表示されます）
- 一致するノードが見つからない場合や、ノードの内容が空の場合はトーストで通知されます
- 比較対象はテキストノードの本文と画像ノードのコメントです。**ノードの種類が異なっていても、内容の文字列が一致すればジャンプ対象になります**（例：テキストノード「猫」と、コメントが「猫」の画像ノードは互いにジャンプできます）
- 公開用HTML（閲覧専用版）でも同じ操作でジャンプできます

## コピー＆ペースト＆カット

| 操作 | 動作 |
|------|------|
| Ctrl + C | 選択中のノードをコピー（単体） |
| Shift + C | 選択中のノードと、それに連なる子孫ノード全体をまとめてコピー（ノードツリー） |
| Ctrl + X | 選択中のノードをコピーし、同時にそのノード単体を削除（切り取り） |
| Ctrl + Shift + X | 選択中のノードと、それに連なる子孫ノード全体をまとめてコピーし、同時に削除（ノードツリーの切り取り） |
| Ctrl + V | クリップボードの画像を画像ノードとして貼り付け |
| Ctrl + Shift + V | コピー済みのノード（またはノードツリー）をマウス位置近くに貼り付け |

- **Ctrl + V** はクリップボードに画像がある場合のみ動作します
- **Ctrl + Shift + V** は、直前に `Shift + C`（または `Ctrl + Shift + X`）でノードツリーをコピーしていればツリーごと貼り付け、そうでなければ `Ctrl + C`（または `Ctrl + X`）でコピーした単体ノードを貼り付けます（ツリーのコピーと単体のコピーは互いの内容を上書きします）
- ノードコピーは色・テキスト・画像・コメント・サイズをすべて引き継ぎます
- ノードツリーのコピーでは、ノード間の接続（親子関係）およびエッジのコメント・線の種類もそのまま引き継がれます
- 貼り付けたノード（ツリー）はルートノードにならず、元のマップとの接続関係は引き継ぎません。ツリー内部の相対位置関係は保たれたまま、マウス位置付近に配置されます
- **Ctrl + X** / **Ctrl + Shift + X** は、コピーと削除を内部的に既存の処理（コピー・削除・Undo/Redo）を組み合わせて行っているだけなので、切り取った内容は通常のコピーと同様に `Ctrl + Shift + V` で貼り付けでき、削除自体も `Ctrl + Z` で元に戻せます。子孫ノードを含む削除（`Ctrl + Shift + L`）とは異なり、確認ダイアログは表示されません
- いずれもブラウザのアクセス許可ダイアログは表示されません

## 保存・読み込み

### クイック保存（Shift+D）

**Shift+D** で現在のマップをその場でダウンロード保存できます。ファイル名はモーダルの入力欄に設定されている名前が使われます。

> タイトル編集中は Shift+D は無効です。

### 公開用HTMLのエクスポート（Shift+P）

**Shift+P** で閲覧専用の公開用HTMLをダウンロードできます。ファイル名は `[ファイル名]_public.html` になります。

> タイトル編集中は Shift+P は無効です。

### ファイルボタンからの操作

「ファイル」ボタンを押すとモーダルが開き、以下の操作ができます。

| ボタン | 動作 |
|--------|------|
| ダウンロード保存 | 現在のマップを `.mindmap` 形式で保存 |
| 公開用 HTML をダウンロード | 閲覧専用の公開用HTMLを保存 |
| ファイルを選択 → 上書き | 選択したファイルで現在のマップを上書き |
| ファイルを選択 → 追加 | 選択したファイルを現在のマップに合成 |

#### ドラッグ＆ドロップでの読み込み

`.mindmap` ファイルを**1つだけ**キャンバスにドロップすると選択オーバーレイが表示され、**「上書き」「追加」「キャンセル」** から選べます。D&D 上書きの場合、保存ファイル名も読み込んだファイル名に自動更新されます。

**複数ファイルの同時ドロップ（v2.03〜）**

`.mindmap` ファイルを**2つ以上まとめて**キャンバスにドロップすると、現在のタブの内容には触れず、ドロップしたファイルの一覧を表示するダイアログが開きます。一覧の各ファイルには「開く」ボタンがあり、1件ずつクリックすることで、それぞれ新しいタブに読み込まれます（上書き/追加の選択は不要）。

- ブラウザは「1回のユーザー操作につきポップアップは1つまで」に制限していることが多く、ドロップ直後に自動で複数タブを連続して開こうとすると、ブラウザのポップアップブロック機能により最初の1件しか開けないことがあります。そのため本機能では、確実なユーザー操作であるボタンクリックを起点として1件ずつ新しいタブを開く方式にしています
- 内部的には `localStorage` を介して元タブから新タブへデータを受け渡しています。受け渡しが完了すると該当データはすぐに削除されるため、恒久的な保存領域は消費しません
- 開いたファイルは一覧上でチェック済み表示になり、すべて開き終えるとダイアログは自動的に閉じます（「閉じる」ボタンでいつでも中断できます）
- 元のタブを読み込み処理の完了前に閉じてしまうと、データの受け渡しができず新しいタブは読み込みに失敗します（10秒でタイムアウトし、失敗のトーストが表示されます）
- フォーマットが不正なファイルが含まれていた場合は、そのファイルのみ読み込み失敗のトーストが表示されます（他の正常なファイルの読み込みには影響しません）
- クリックしても万一ブロックされた場合は、該当ファイルのボタンが再度クリック可能な状態に戻り、ポップアップ許可を促すトーストが表示されます

### 上書き・追加の違い

| モード | 動作 |
|--------|------|
| 上書き | 現在のマップを破棄し、読み込んだマップを適用する |
| 追加 | 現在のマップに読み込んだマップを合成する（ID衝突なし） |

> 読み込み時に存在しないノードを参照するゴーストエッジは自動的に除去されます。  
> 画面外にノードが配置されている場合は自動的にシフトされます。  
> 「上書き」読み込み完了後は、自動的にID最小のノードが画面中央に表示されます（「追加」読み込み時は表示位置を変更しません）。

### データ形式

`MINDMAP v2` 形式のプレーンテキストです。

```
MINDMAP v2
TITLE プロジェクト計画
NODE 0 0 1 340 250 マインドマップ
NODE 1 1 0 180 130 アイデアA\n2行目テキスト
IMGNODE 5 240 400 200 コメント||data:image/png;base64,...
ATTR 0 https%3A%2F%2Fexample.com|%E3%82%BF%E3%82%B0A%2C%E3%82%BF%E3%82%B0B|%E5%AE%8C%E4%BA%86
EDGE 0 1
COLLAPSED 3,5
META nodeId=6
```

| フィールド | 説明 |
|-----------|------|
| `TITLE` | マップタイトル（デフォルトと同じ場合は省略） |
| `NODE` | `id / colorIdx / isRoot / x / y / テキスト`（改行は `\n` でエスケープ） |
| `IMGNODE` | `id / 幅(px) / x / y / コメント\|\|画像データ(Base64)` |
| `ATTR` | `id / URL\|タグ(カンマ区切り)\|ステータス`（各値は `encodeURIComponent` でエンコード。URL・タグ・ステータスがすべて未設定のノードは行自体を省略） |
| `EDGE` | `from_id to_id`（fromが親、toが子） |
| `COLLAPSED` | 折り畳み中の親ノードIDのカンマ区切り |
| `META` | 次に割り当てるノードIDを記録 |

> `ATTR` 行が存在しないファイル（v1.x系で保存したファイル）を読み込んだ場合も、該当ノードのURL・タグ・ステータスは単に空として扱われるため問題なく読み込めます（後方互換）。

## エッジの矢印表示

ノード間を結ぶエッジには親から子の方向を示す矢印が表示されます。

- 矢印は**子ノード側**の端に表示され、親→子の向きを示します
- 矢印サイズはズームレベルに連動し、ズームインで大きく・ズームアウトで小さく表示されます
- ノードの長さや角度に応じて矢印先端がノードの縁に正確に合わせて表示されます
- エッジのライン色と矢印の色は同一の不透明色（ライト: `#aaa8a0` / ダーク: `#6e6c66`）で統一されており、重なり部分で色が濃くなる現象はありません
- ノードにホバーすると、関連するエッジの矢印もエッジと同じオレンジ色でハイライトされます
- 編集用HTML・公開用HTMLの両方に対応しています

## エッジのコメント・線の種類

エッジ（ノード同士を結ぶ線）に短いコメントを添えたり、線の種類を変更したりできます。

- **設定画面を開く**：エッジ（線）を右クリックすると「エッジの設定」モーダルが開きます
- **線の種類**：4種類から選べます。選択するとすぐにプレビューがハイライトされ、「保存」を押すと反映されます

  | 種類 | 見た目 | 矢印 | 接続位置 |
  |------|--------|------|----------|
  | 実線＋矢印（既定） | ──> | あり | 子ノード側は境界手前で止まる |
  | 破線＋矢印 | -----> | あり | 子ノード側は境界手前で止まる |
  | 実線（矢印なし） | ─── | なし | 両ノードの中心同士を接続 |
  | 破線（矢印なし） | - - - - | なし | 両ノードの中心同士を接続 |

  矢印なしのスタイルは、ノードの中心同士を結ぶ形で描画されます（ノードに隠れる部分は自動的に見えなくなるため、見た目には境界で止まっているのと同じに映ります）
- **コメント**：テキスト（最大60文字）を入力して「保存」すると、線の上にコメントが表示されます
- **保存・キャンセル**：入力欄でのEnter、またはShift+Enterで保存、Escapeでキャンセルできます（入力欄・ボタンのどこにフォーカスがあっても有効）
- **コメントの削除**：モーダルの「クリア」ボタンでコメントのみ削除できます（線の種類は維持されます）
- **表示位置**：コメントは、両ノードに隠れて見えない部分を除いた「実際に画面上で見えているエッジ」の、線に沿った中央（弧長の中点）に自動的に配置されます。矢印の有無や接続位置の違いに関わらず、常に見た目の中央に一致するよう計算されます
- **クリック判定**：線そのものは細いため、右クリックの当たり判定は見た目より少し広め（透明な帯）に取ってあり、線の近くであれば反応します
- ホバー時のハイライトも、線の種類（太さ・矢印の有無）を保ったまま強調表示されます
- 編集用HTML・公開用HTMLの両方に対応しています（公開用HTMLでは表示のみで、編集はできません）
- データは独自形式（`MINDMAP v2`）の `EDGE from to [線の種類] [コメント]` という行に保存されます。既定（実線＋矢印）の場合は線の種類を省略するため、これまで通り `EDGE from to` または `EDGE from to コメント` の形式のファイルも問題なく読み込めます

### ノード選択時のキーボード操作

> ノードを選択した状態（クリックして選択状態にした直後）で使えます。テキスト入力欄やモーダル（画像編集・エッジコメント編集）にフォーカスがある間は無効です。

| キー | 動作 |

## 未保存時の閉じる確認

編集操作（ノードの追加・削除・移動・テキスト変更・色変更など）を行った後、`.mindmap` ファイルとしてダウンロード保存せずにブラウザを閉じようとすると、ブラウザ標準の確認ダイアログが表示されます。

- 「このページを離れますか？」のダイアログでページを離れると、未保存の変更は失われます
- 「キャンセル」を選ぶとページに戻り、引き続き編集・保存ができます
- **Shift+D** またはモーダルの「ダウンロード保存」を実行すると未保存フラグがリセットされ、次に閉じる際はダイアログが表示されません
- 公開用HTML（`_public.html`）はダウンロードしても未保存フラグはリセットされません（`.mindmap` 形式での保存が必要です）
- この機能は編集用HTMLのみ対象です（公開用HTMLは閲覧専用のため対象外）
