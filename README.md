# 🗺 マインドマップアプリ 使い方ガイド

**ファイル名:** `mindmap.html`

## 起動方法

`mindmap.html` をブラウザ（Chrome / Edge / Firefox / Safari）で開くだけで使えます。インストール不要・1ファイル完結です。初回のみアイコンフォントの読み込みにインターネット接続が必要です。

---

## ノードの基本操作

| 操作 | 動作 |
|------|------|
| 左クリック | ノードを選択 |
| 左クリック＆ドラッグ | ノードを移動（単体） |
| Ctrl + 左クリック（空白） | その場に新しいノードを追加し、すぐ編集開始 |
| Ctrl + 左クリック（ノード上） | 子ノードの展開／折り畳みをトグル |
| Ctrl + 左クリック＆ドラッグ | ノードと全子孫をまとめて移動 |
| Shift + 左クリック（テキストノード） | ノードの色を順番に切り替え（6色ループ） |
| 右クリック | テキスト編集 / 画像モーダルを開く |
| Shift + 右クリック | ノードを削除 |
| Ctrl + 右クリック × 2 | 2ノードを接続 / すでに接続済みなら解除 |

### テキスト編集（右クリックで開始）

- **Enter** で改行を挿入
- **Shift + Enter** で編集確定
- **ノードの外をクリック**しても確定
- **Escape** でキャンセル（元のテキストに戻る）
- 編集中はズームレベルに関係なく常に一定サイズで全文字が表示されます
- 1行のとき：中央配置・横幅が内容に合わせて伸びる
- 2行以上のとき：左寄せ配置・最長行の幅に合わせて広がる

## キャンバス操作

| 操作 | 動作 |
|------|------|
| ホイールスクロール | カーソル位置を中心にズームイン／アウト（20%〜400%） |
| 左クリック＆ドラッグ（空白） | ビューをパン（ノード位置は変わらない） |
| Shift + 左クリック＆ドラッグ | 全ノードをまとめて移動 |

## 親子ノード機能

### 親子関係の定義

接続した順番で **先に選んだノードが親・後が子** になります。子を持つ親ノードには `▶` マーク、折り畳み中は `▶▶` マークが表示されます。

### 展開・折り畳み

| 操作 | 動作 |
|------|------|
| Ctrl + 左クリック（親ノード） | 直接の子ノードのみ展開／折り畳み |
| Shift + Q | 全ノードを展開 |
| Shift + W | 全ノードを折り畳み |

> 孫ノードは子ノードを別途 Ctrl+クリックで操作します。

### 連動移動

- **Ctrl + ドラッグ**：親ノードと全子孫ノードをまとめて移動
- **通常ドラッグ**：そのノードのみ移動

折り畳み状態は保存データに含まれ、読み込み後も復元されます。

### ループ接続の禁止

接続操作の際、親子関係がループする接続（例：A→B→C→A）は自動的に検出され、トーストメッセージで警告のうえ拒否されます。既存接続の解除は通常通り行えます。

## 検索機能

| 操作 | 動作 |
|------|------|
| Ctrl + F | 検索欄にフォーカス |
| テキスト入力 | リアルタイムで該当ノードをハイライト、最初のノードを画面中央に表示 |
| Enter または ▼ボタン | 次の結果へ移動（画面中央に表示） |
| ▲ボタン | 前の結果へ移動 |
| Escape | 検索クリア |

- 🟠 オレンジ枠：検索に一致するノード
- 🔴 赤枠：現在フォーカスしているノード
- テキストノードのテキスト・画像ノードのコメントの両方が検索対象

---

## コピー＆ペースト

| 操作 | 動作 |
|------|------|
| Ctrl + C | 選択中のノードをコピー |
| Ctrl + V | クリップボードの画像を画像ノードとして貼り付け |
| Ctrl + Shift + V | コピー済みノードをマウス位置近くに貼り付け |

- **Ctrl + V** はクリップボードに画像がある場合のみ動作します
- **Ctrl + Shift + V** は `Ctrl + C` でコピーしたノードを貼り付けます
- ノードコピーは色・テキスト・画像・コメント・サイズをすべて引き継ぎます
- 貼り付けたノードはルートノードにならず、接続関係は引き継ぎません
- いずれもブラウザのアクセス許可ダイアログは表示されません

## 画像ノード

### 追加方法

| 方法 | 操作 |
|------|------|
| ドラッグ＆ドロップ | 画像ファイルをキャンバスへドロップ（複数枚同時可） |
| ファイル選択 | ツールバー「画像追加」ボタンから選択 |
| クリップボード貼り付け | スクリーンショット等の後 Ctrl+V |

### 編集（右クリックでモーダルを開く）

- **コメント**：自由にテキストを入力・編集（全文表示）
- **表示サイズ**：スライダーで幅を変更（80px〜500px、10px刻み）。縦横比は自動維持

### 表示仕様

- 画像は実際のアスペクト比を保ったまま全体表示されます
- 横長・縦長いずれの画像も正しく表示されます（最大幅 400px）
- コメントは長文でも切れずに全文表示されます

## タイトルの変更

ヘッダーの「🗺 マインドマップ」部分をクリックするとその場で編集できます。

- **Enter** または外をクリックで確定
- ブラウザのタブタイトルも連動して変わります
- 保存データに含まれ、読み込み後も復元されます

## ツールバー

| ボタン | 動作 |
|--------|------|
| Undo | 直前の操作を元に戻す（最大80ステップ） |
| Redo | やり直す |
| ノード追加 | 中央付近にランダム色でノードを追加 |

| 画像追加 | ファイルダイアログから画像ノードを追加 |
| カラードット（6色） | 選択中のテキストノードの色を変更 |
| 削除 | 選択中のノードを削除 |
| ファイル | 保存・読み込みモーダルを開く |
| 検索欄 | ノードのテキスト・コメントを検索 |

## 保存・読み込み

### ファイル保存

「ファイル」ボタン → ファイル名を入力 → 「ダウンロード保存」で `.mindmap` ファイルを保存します。

### ファイル読み込み（2つの方法）

#### ① ファイルボタンから

「ファイル」モーダルの「ファイルを選択」から `.mindmap` ファイルを選ぶと、**「上書き」「追加」** の2つのボタンが有効になります。

#### ② ドラッグ＆ドロップ

`.mindmap` ファイルをキャンバスにドロップすると選択オーバーレイが表示され、**「上書き」「追加」「キャンセル」** から選べます。

### 上書き・追加の違い

| モード | 動作 |
|--------|------|
| 上書き | 現在のマップを破棄し、読み込んだマップを適用する。保存ファイル名も読み込んだファイル名に自動更新される |
| 追加 | 現在のマップに読み込んだマップを合成する（ID衝突なし） |

> 読み込み時に存在しないノードを参照するゴーストエッジは自動的に除去されます。  
> 画面外（ヘッダー裏など）にノードが配置されている場合は自動的にシフトされます。

### データ形式

`MINDMAP v2` 形式のプレーンテキストです。

```
MINDMAP v2
TITLE プロジェクト計画
NODE 0 0 1 340 250 マインドマップ
NODE 1 1 0 180 130 アイデアA\n2行目テキスト
IMGNODE 5 240 400 200 コメント||data:image/png;base64,...
EDGE 0 1
COLLAPSED 3,5
META nodeId=6
```

| フィールド | 説明 |
|-----------|------|
| `TITLE` | マップタイトル（デフォルトと同じ場合は省略） |
| `NODE` | `id / colorIdx / isRoot / x / y / テキスト`（改行は `\n` でエスケープ） |
| `IMGNODE` | `id / 幅(px) / x / y / コメント\|\|画像データ(Base64)` |
| `EDGE` | `from_id to_id`（fromが親、toが子） |
| `COLLAPSED` | 折り畳み中の親ノードIDのカンマ区切り |
| `META` | 次に割り当てるノードIDを記録 |

## 動作環境

- **推奨ブラウザ**：Chrome 90以降
